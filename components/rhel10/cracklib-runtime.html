Install cracklib-runtime Package

package_cracklib-runtime_installed

Description

The cracklib-runtime package can be installed with the following command: 

$ sudo dnf install cracklib-runtime

Rationale

The cracklib-runtime package supplies the password dictionary tools used by PAM password-quality controls.
