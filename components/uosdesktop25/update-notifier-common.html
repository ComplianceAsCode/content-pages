Disable and Mask update-notifier-motd Service

service_update-notifier-motd_disabled

Description

The update-notifier-motd service generates dynamic message-of-the-day content. The update-notifier-motd service can be disabled with the following command: 

$ sudo systemctl mask --now update-notifier-motd.service

Rationale

Disabling dynamic MOTD updates prevents unaudited network and system data from being added to login banners.

Disable and Mask update-notifier-motd Timer

timer_update-notifier-motd_disabled

Description

The update-notifier-motd.timer unit must be inactive and not enabled when the update-notifier-common package is installed. Masking is the preferred remediation because it also prevents transient activation.

Rationale

Disabling the timer prevents periodic regeneration of dynamic login message content.
