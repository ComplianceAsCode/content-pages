Rule details

Disable Installation of Weak Dependencies in Zypper

zypper_only_requires_enabled

Description

To disable weak dependencies, set the solver.onlyRequires option to true in the /etc/zypp/zypp.conf file.

Rationale

Weak dependencies (such as recommended packages) can introduce unneeded software components on the system, increasing the attack surface. Disabling them ensures that only packages strictly required for operations are installed.
